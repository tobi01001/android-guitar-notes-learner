USER INTERACTION FLOWS
======================

Flow 1: Complete Time-based Session
------------------------------------
Home → Config → Ready → [Start] → Active
     → [wait 5 min] → Completed → [Finish] → Config


Flow 2: Complete Count-based Session
-------------------------------------
Home → Config → Ready → [Start] → Active
     → [Next] × 20 → Completed → [Finish] → Config


Flow 3: Pause and Resume
-------------------------
Active → [Pause] → Paused → [Resume] → Active


Flow 4: Early Termination
--------------------------
Active → [End Session] → Completed → [Finish] → Config


Flow 5: Change Mind Before Starting
------------------------------------
Ready → [Back] → Config

RESPONSIVE LAYOUT
=================

Vertical arrangement:
1. Progress Section (top)
   - Progress bars
   - Statistics text

2. Note Display (center)
   - Large note name
   - Position information
   - Primary container card

3. Controls (bottom)
   - Primary action button
   - Row of secondary buttons

Spacing:
- Section spacing: 24dp
- Button spacing: 12dp
- Card padding: 32dp
- Screen padding: 24dp

Font Sizes:
- Display Large: 96sp (note name)
- Title Large: 24sp (position, instructions)
- Title Medium: 16sp (progress text)


COLOR SCHEME (Material 3)
==========================

Primary Container:
- Background: primaryContainer
- Text: onPrimaryContainer
- Used for: Note display card

Progress Bars:
- Progress: primary
- Background: surface variant

Buttons:
- Primary: primary background
- Secondary: outlined with primary

Text:
- Primary: onSurface
- Secondary: onSurfaceVariant
- Error: error (for validation)


ACCESSIBILITY
=============

- All buttons have descriptive text
- Progress bars have labels
- Note display is large and clear
- Sufficient contrast ratios
- Touch targets ≥ 48dp
- Screen reader friendly
- Semantic content structure


ANIMATION OPPORTUNITIES
=======================

Future Enhancements:

- Progress bar smooth updates
- Completion celebration animation
