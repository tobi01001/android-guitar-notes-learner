Validation States
===========================================

Error Example (No strings selected):
  Select Strings
  ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐
  │   │ │   │ │   │ │   │ │   │ │   │  (all unselected)
  └───┘ └───┘ └───┘ └───┘ └───┘ └───┘
  ⚠ Select at least one string            ← Error message


Error Example (Invalid fret range):
  Fret Range
  ┌─────────────┐   —   ┌─────────────┐
  │ From Fret   │       │ To Fret     │
  │    15       │       │     5       │  (From > To)

Material Design 3 Features
===========================================

- FilterChips: Toggleable chips with selected/unselected states
- OutlinedTextField: Text input with floating labels
- RadioButton: Single selection from multiple options
- Button: Primary action (Start Practice)
- OutlinedButton: Secondary action (Back)
- Scaffold: Top app bar + content layout
- Column with spacedBy: Consistent spacing
- Scrollable: Works on all screen sizes


Color Scheme (Material 3)
===========================================

- Primary: Action buttons, selected chips
- OnPrimary: Text on primary color
- Error: Error messages
- Surface: Background
- OnSurface: Text on surface
